# DIY Accounting Submit for Claude

Work out a UK VAT return from a book you saved in DIY Accounting Submit, check the nine boxes with Claude, and read the receipt afterwards.

## Use it

Connect the DIY Accounting Submit connector and sign in. Ask Claude to work out your VAT return for a quarter. Claude opens the book you name, shows the nine boxes with the lines behind them, and tells you where to file. You file the return yourself on the Submit page, where you tick the declaration. Ask Claude to read the receipt when you are done.

## Data

The plugin sends the book you ask Claude to open, and the period you name, to submit.diyaccounting.co.uk through the connector. It stores nothing itself. No tool in the connector files a return or pays HMRC.

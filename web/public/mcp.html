DIY Accounting Submit

MCP server

Work out a VAT return from your bookkeeping in an AI assistant

Status of each feature. Sandbox and preview features file nothing real. See the availability table.

    Can an AI assistant file my VAT return?

    Not through the hosted connector. It lets an assistant such as Claude open a DIYA-GL book you saved, work out the nine VAT return boxes for a period, read your stored receipts and give you a link that opens the VAT form with the figures filled in. You check them, tick the declaration and file the return yourself, in your browser.

    What you need first

    The connector works out a VAT return from a DIYA-GL book saved in your account. Before you add it to an assistant, you need:

    1. A DIY Accounting Submit account. Sign in or create one; the assistant signs in with the same account.
    2. A DIYA-GL book saved in that account. A DIYA-GL book is one business's sales, purchases and bank lines. Keep your bookkeeping in DIYA-GL, which runs in your browser, and sign in there with the same account: DIYA-GL saves the book to it.
    3. The business registered for VAT, and the book holding the whole of the VAT quarter you want to work out.

    What is MCP?

    The Model Context Protocol (MCP) is a standard way for an AI assistant to use another service.

    DIY Accounting offers three ways in: the hosted connector, which a chat client reaches with one URL; the diya-gl MCP server for reading and editing a DIYA-GL book; and the submission MCP you run yourself for filing VAT returns and Companies House accounts. Every filing they make is one the web app can make too.

    The hosted connector

    The hosted connector gives a chat client your saved DIYA-GL books and the VAT derivation, with nothing to install. It signs in with the same account as the web app.

    The connector URL is:

    https://submit.diyaccounting.co.uk/mcp

    ChatGPT plugin

    In ChatGPT, add the DIY Accounting Submit plugin from its listing: chatgpt.com/plugins/plugin_asdk_app_6af90052c7f08191b817bdecceff0362. Sign in to your account when ChatGPT asks, then ask, for example, “Work out my MTD VAT return for the quarter ended 30 June 2025.”

    Add it in Claude

    This works in Claude on the web, in Claude Desktop, on mobile and in Cowork.

    1. Open Settings, then Connectors. On the web the page is claude.ai/customize/connectors.
    2. Choose Add, then Add custom connector.
    3. Enter the name DIY Accounting Submit and the connector URL above, then choose Continue. Claude checks the server and the sign-in settings.
    4. Keep the sign-in options Claude has chosen, then choose Add.
    5. Choose Connect. Claude opens the page “Allow access to DIY Accounting Submit”. Choose Continue.
    6. Sign in to your account. Claude returns to the connector page, which now shows Disconnect.

    In a new chat, open the + menu, choose Connectors and check that DIY Accounting Submit is on. Then ask, for example, “Work out my MTD VAT return for the quarter ended 30 June 2025.” Claude asks before it uses each tool. Choose Allow once, or Always allow for a tool you trust. Claude shows the nine boxes of a VAT return as a card, with a link to open the VAT form with the figures filled in.

    In Claude Code, run:

    claude mcp add --transport http diya-submit https://submit.diyaccounting.co.uk/mcp

    Then run /mcp in Claude Code and choose the server to sign in.

    Add it in Gemini

    This works in Gemini on the web with a personal Google account.

    1. Open Gemini, choose the settings gear at the foot of the sidebar, then Connected apps. The page is gemini.google.com/customize/connectors.
    2. Choose + Custom. The dialog “Connect to an MCP server” opens.
    3. Paste the connector URL above into MCP server URL, then choose Next.
    4. Read the consent text in “Connect this MCP server” to its end, then choose Connect.
    5. Google asks you to link your Google Account and the Diyaccounting account. Choose Continue.
    6. Sign in to your account on the DIY Accounting Submit page.
    7. In “Save your custom app”, keep the name DIY Accounting Submit. It lists the eleven tools under Available actions. Choose Connect.

    The connector now shows under Custom apps. In a new chat, ask “Work out my MTD VAT return for the quarter ended 30 June 2025.” Gemini asks which DIYA-GL book to use, then shows the nine boxes.

    Tools

    The connector has eleven tools. It does not reach HMRC and it files nothing.

    list_books
    List the DIYA-GL books saved in your account, most recently updated first.
    open_book
    Open a saved DIYA-GL book by its id. It reports the product, the period covered and the book's checks.
    derive_vat_return
    The nine VAT return boxes for one period of the open book, with the lines that fed them.
    prepare_vat_return
    The same figures for one period, with a link that opens the VAT form on this site with them filled in. The assistant files nothing.
    list_vat_receipts, get_vat_receipt
    List the VAT receipts Submit stored for your account, and read one.
    company_filing_deadlines
    When a company's next accounts and confirmation statement are due, from the Companies House public register.
    derive_micro_entity_accounts, derive_small_company_accounts
    The figures a company's micro-entity or small company accounts take, from the open DIYA-GL book.
    derive_company_tax_return
    The figures a Company Tax Return (CT600) takes, from the open DIYA-GL book of a company.
    list_accounts_receipts
    List the accounts filings Submit stored for your account, accepted and rejected.

    Open the link in your browser, check the figures, tick the declaration and file the return there. Nothing reaches HMRC until you do.

    The diya-gl MCP server

    diya-gl-mcp reads and edits a diya-gl book — the small set of files behind a DIY Accounting Spreadsheets workbook — from an MCP client such as Claude Desktop or Claude Code. It comes from the DIY Accounting Spreadsheets product, in the @diy-accounting-uk/diya-gl npm package.

    Install it:

    npm install -g @diy-accounting-uk/diya-gl

    Run it:

    diya-gl mcp

    Point an MCP client at diya-gl-mcp (or diya-gl mcp) with no arguments. Four tools:

    extract_book
    Loads a workbook or package zip into a book, its computed report, and its checks and warnings.
    report
    Works out the figures, report sections and compliance checks for the book that is loaded.
    edit_lines
    Applies one named change to the book's transaction lines and returns the recalculated figures.
    save_workbook
    Writes the book back out as a workbook, a package zip, a diya-gl zip, or a JSON file.

    The submission MCP on your computer

    The submission MCP takes a customer's DIYA-GL book and files the VAT return to HMRC and the micro-entity accounts to Companies House. It works out the figures a filing needs, shows them for confirmation, and only then sends the filing. It also works out the Self Employment quarterly update and annual submission figures for Income Tax (MTD).

    Run it from npm

    It needs Node.js 24 or later. Run it without installing:

    npx @diy-accounting-uk/diya-submit

    Run it from Docker

    The image runs the same server over stdin and stdout, so a client starts it with docker run -i:

    docker run -i --rm ghcr.io/diy-accounting-uk/diya-submit-mcp

    Connect a client

    Add the server to an MCP client such as Claude Desktop or Claude Code. For the npm package the client's configuration entry is: 

    {
  "mcpServers": {
    "diya-submit": {
      "command": "npx",
      "args": ["-y", "@diy-accounting-uk/diya-submit"],
      "env": {
        "DIYA_SUBMIT_BASE_URL": "https://submit.diyaccounting.co.uk",
        "DIYA_SUBMIT_AUTH_DOMAIN": "prod-auth.diyaccounting.co.uk",
        "DIYA_SUBMIT_MCP_CLIENT_ID": "5gpesn0rvb5vidtupcrgakq6tg"
      }
    }
  }
}

    For the Docker image, set "command": "docker" and "args": ["run", "-i", "--rm", "-e", "DIYA_SUBMIT_BASE_URL", "-e", "DIYA_SUBMIT_AUTH_DOMAIN", "-e", "DIYA_SUBMIT_MCP_CLIENT_ID", "ghcr.io/diy-accounting-uk/diya-submit-mcp"] with the same env block.

    Sign in

    Ask the client to run sign_in. It opens the same sign-in page the web app uses, catches the answer on a local address, and keeps a refresh token in ~/.config/diya-submit/credentials.json readable only by you. Run sign_out to revoke it. HMRC's own grant stays a browser step, and a Companies House authentication code is passed on the one call that files and is not stored. In the Docker image the credentials file lives inside the container, so mount a volume at /home/node/.config/diya-submit to keep the sign-in between runs.

    Tools

    open_book, save_book
    Open a book from a file or from your account, and save it back in any of the four formats.
    list_vat_obligations
    The open and fulfilled VAT obligations HMRC holds for a business.
    derive_vat_return
    The nine VAT return boxes for a period, with the lines that fed each box.
    submit_vat_return, get_vat_receipt
    File a confirmed VAT return with HMRC, and fetch the stored receipt.
    derive_micro_entity_accounts
    The seven micro-entity balance sheet figures for the current and prior year.
    render_micro_entity_accounts_sandbox, submit_micro_entity_accounts_sandbox, poll_submission
    Render the filing, file confirmed accounts with Companies House, and check the filing's outcome.
    revision on the accounts tools
    Files revised accounts that replace accounts already filed for the same period, saying what was wrong and what changed. Its revisesReceipt names the receipt of the accepted accounts it revises, which Submit checks.
    derive_itsa_quarterly_update, derive_itsa_annual_submission
    The Self Employment figures for one quarter and for the year, from a self-employed book.

    A submit tool takes the figures the derive tool returned, never a book, so you see and approve the figures before anything reaches HMRC or Companies House.

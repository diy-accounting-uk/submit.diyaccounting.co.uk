What is MCP?

The Model Context Protocol (MCP) is an open standard for connecting AI applications to external data sources, tools, and workflows. Think of MCP like a USB-C port for AI applications — just as USB-C provides a standardised way to connect devices, MCP provides a standardised way to connect AI assistants to external systems.

Two MCP servers exist for DIY Accounting's own tools: the diya-gl MCP server for reading and editing a book, available now, and the submission MCP for filing VAT returns and Companies House accounts. Every filing they make is one the web app can make too.

Available now

The diya-gl MCP server

diya-gl-mcp reads and edits a DIYA-GL book — the small set of files behind a DIY Accounting Spreadsheets workbook — from an MCP client such as Claude Desktop or Claude Code. It comes from the DIY Accounting Spreadsheets product, in the @diy-accounting-uk/diya-gl npm package.

Install it:

npm install -g @diy-accounting-uk/diya-gl

Run it:

diya-gl mcp

Point an MCP client at diya-gl-mcp (or diya-gl mcp) with no arguments. Four tools:

extract_book
Loads a workbook or package zip into a book, its computed report, and its checks and warnings.
report
Works out the figures, report sections and compliance checks for the book that is loaded.
edit_lines
Applies one named change to the book's transaction lines and returns the recalculated figures.
save_workbook
Writes the book back out as a workbook, a package zip, a diya-gl zip, or a JSON file.

The submission MCP

The submission MCP takes a customer's book and files the two submissions this service makes: the VAT return to HMRC and the micro-entity accounts to Companies House. It works out the figures a filing needs, shows them for confirmation, and only then sends the filing. It also works out the Self Employment quarterly update and annual submission figures for Income Tax (MTD).

Run it from npm

It needs Node.js 24 or later. Run it without installing:

npx @diy-accounting-uk/diya-submit

Run it from Docker

The image runs the same server over stdin and stdout, so a client starts it with docker run -i:

docker run -i --rm ghcr.io/diy-accounting-uk/diya-submit-mcp

Connect a client

Add the server to an MCP client such as Claude Desktop or Claude Code. For the npm package the client's configuration entry is: 

{
  "mcpServers": {
    "diya-submit": {
      "command": "npx",
      "args": ["-y", "@diy-accounting-uk/diya-submit"],
      "env": {
        "DIYA_SUBMIT_BASE_URL": "https://submit.diyaccounting.co.uk",
        "DIYA_SUBMIT_AUTH_DOMAIN": "prod-auth.diyaccounting.co.uk",
        "DIYA_SUBMIT_MCP_CLIENT_ID": "5gpesn0rvb5vidtupcrgakq6tg"
      }
    }
  }
}

For the Docker image, set "command": "docker" and "args": ["run", "-i", "--rm", "-e", "DIYA_SUBMIT_BASE_URL", "-e", "DIYA_SUBMIT_AUTH_DOMAIN", "-e", "DIYA_SUBMIT_MCP_CLIENT_ID", "ghcr.io/diy-accounting-uk/diya-submit-mcp"] with the same env block.

Sign in

Ask the client to run sign_in. It opens the same sign-in page the web app uses, catches the answer on a local address, and keeps a refresh token in ~/.config/diya-submit/credentials.json readable only by you. Run sign_out to revoke it. HMRC's own grant stays a browser step, and a Companies House authentication code is passed on the one call that files and is not stored. In the Docker image the credentials file lives inside the container, so mount a volume at /home/node/.config/diya-submit to keep the sign-in between runs.

Tools

open_book, save_book
Open a book from a file or from the DIYA cloud, and save it back in any of the four formats.
list_vat_obligations
The open and fulfilled VAT obligations HMRC holds for a business.
derive_vat_return
The nine VAT return boxes for a period, with the lines that fed each box.
submit_vat_return, get_vat_receipt
File a confirmed VAT return with HMRC, and fetch the stored receipt.
derive_micro_entity_accounts
The seven micro-entity balance sheet figures for the current and prior year.
preview_micro_entity_accounts, submit_micro_entity_accounts, poll_accounts_submission
Preview the filing, file confirmed accounts with Companies House, and check the filing's outcome.
derive_itsa_quarterly_update, derive_itsa_annual_submission
The Self Employment figures for one quarter and for the year, from a self-employed book.

A submit tool takes the figures the derive tool returned, never a book, so you see and approve the figures before anything reaches HMRC or Companies House.

A hosted version, reachable from a chat client without installing anything, is in development. It will use the same account as the web app.

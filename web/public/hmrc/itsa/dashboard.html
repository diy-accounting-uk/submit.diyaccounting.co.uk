Making Tax Digital for Income Tax

Quarterly updates for the self-employed and landlords

Activities Receipts Bundles Spreadsheets
⚠️ SYNTHETIC MODE - calls go to HMRC's sandbox API

Making Tax Digital for Income Tax replaces the annual Self Assessment return with a running record: self-employed people and landlords send HMRC a summary of income and expenses every quarter instead of once a year. This preview runs against HMRC's sandbox in every environment except production.

1. Business Details

Look up the self-employment and property businesses HMRC holds against your National Insurance number.

Go to Business Details

2. Obligations

Check which quarterly updates are open, due, or already sent for a business.

Go to Obligations

3. File a Quarterly Update

Send a self-employment period summary of income and expenses to HMRC.

Go to File a Quarterly Update

4. Period Summaries

List the quarterly updates already filed for a self-employment business.

Go to Period Summaries

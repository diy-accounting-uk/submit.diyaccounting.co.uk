# Cost per merged change, 2026 vendor reports

- Databricks internal benchmark on real merged PRs, July 2026: $1.28 to $2.09 per task.
- Warp: factory cost per PR cut from $80 to $30 by choosing the default model mix.
- Jellyfish, 100 million PRs: median cost per merged PR across companies $820; AI's direct share about $18.
- Larridin: $10.97 and $29.62 per merged-PR outcome for two agents at one customer.
- The sources define the unit differently (task, session, PR, outcome); none is Claude Code specific.

# wake — come back up

**Read `.claude/skills/cool-down/SKILL.md` and follow its "Waking up" section.** That is this
skill's whole content. Each rule there carries its own Waking note, so the way back up sits
beside the rule it undoes and the two cannot drift apart.

Three things this skill adds, and nothing else:

**Only the operator wakes a session**, in their own words. "Carry on" or "resume" is enough.
Silence is not consent, an idle hour is not consent, and a green branch is not consent.

**The seven steps run in order**, because each depends on the one before. If any cannot be
completed, say which and why and stay cool. A half-woken session with a red branch and an
unaccounted worktree is worse than one still cooling.

**Waking ends with a board render**, as cooling down does, and the same four-line report:
agents, branches, board, next. If waking takes longer than 60 minutes, render at that point
anyway and carry on.

If cool-down is not on, say so and do nothing. There is nothing to wake from.
